# Setup Agent Team

这是一次性环境安装入口，与日常 `agent-team` 协作分开。用户显式调用 `$setup-agent-team` 或明确要求使用此技能安装/修复环境时执行；不因新对话、启用团队、恢复任务或切换目录自动运行。

1. 开始时明确告知“正在调用 setup-agent-team 安装团队依赖”。从用户指令和当前上下文确定实际主机、目标工作区与安装范围；默认当前工作区，默认标准工程 Skills，UI 工具及其他依赖按任务选择。读取适用项目规则，保留已有技能及自定义配置。
2. 读取 [依赖安装指引](references/dependencies.md)，执行所选范围的检查和缺失项安装。已有可用项跳过，修复只复核受影响项。Skills 固定来源路径见 [清单](references/matt-skills.json)。不加载全部上游技能正文，不启动业务子 Agent，不修改全局登录或自动发布；原生角色配置仅在用户要求时安装。
3. 记录安装摘要并汇报安装/保留项、实际验证及未解决问题。磁盘安装、会话发现、正文读取和实际执行分别说明；宿主未刷新时提示新会话发现，不能承诺热加载。环境准备不代替规格确认或业务验收。

日常团队任务直接按所需技能执行；不要求再次运行本技能或检查摘要。实际出现缺失/不可运行的依赖时，说明调用本技能的具体原因，在当前授权范围内仅补受影响项；超出安装范围时等待用户明确指令。项目测试、design.md lint 与 UI Check 仍在对应业务阶段执行。
