# 协作时间线 v1 候选 UX

状态：待用户确认；不作为已批准实施基线。主图 main.png，补充图 states.png；提示词 prompts.md。生成者为实际 `/root/timeline_ue`，使用内置 image_gen；所有示例均为演示数据，深色补充图2024日期是生成文字误差，不采纳为数据/规范。

保留现有顶部工作区、团队、同步信息和导航，新增协作时间线。桌面采用时间线列表和右侧事件详情，窄屏390px筛选换行、时间放入卡片、详情变抽屉。浅色主图确定主要组件层次，补充图确定深色、窄屏和异常状态的处理方向，精确token沿用现有已确认design.md，未在本轮生成新正式规范。

事件卡显示分派/消息/回复/状态、发送方→接收方、正文、时间、来源和任务/执行。正文纯文本；长消息四行后可展开/收起，详情展示全文。按任务、Agent和事件类型组合筛选；Agent同时匹配发送和接收方，同名实例保持明确标识。不把角色名推测为未提供的身份。

点击事件打开详情，关联任务/执行联动既有详情并保存筛选/阅读位置。回复按replyTo定位原消息，筛选隐藏时明确提供调整筛选操作；原消息未接入时保持未知并说明不可定位。事件时间来自生产者声明，区分真实发生时间、观察/回报时间和recordedAt；本会话现有明确回报时间不冒充原生工具精确发生时间。缺失字段明确未知。

默认旧到新，同时间按稳定sequence/id排序；游标使用归档sequence。刷新保留选中和阅读位置，正在阅读不自动滚到底，新事件数量及查看动作可见。初次加载骨架，无交互和筛选无结果分别说明；断线保留最近快照与成功同步时间、可重试；恢复补齐去重。按系统主题/减少动效，键盘可导航、Esc关闭详情并恢复焦点。

确认对象覆盖两图及上述交互。正式UI实施前需用户明确确认、归档版本及指纹，并补充design.md规范和实际lint。交付需真实浅/深色、桌面/窄屏、长消息、空态/加载/断线/缺失关联截图对照和UI Check；静态图不证明交互可用。
