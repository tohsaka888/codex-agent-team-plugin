# 协作时间线 v1 实施说明

用户确认依据为[decision.md](decision.md)，批准图和UX原文保持不变；ux.md的待确认字样为呈交历史，不代表当前实施未获确认。正式补充规范见根design.md的协作时间线v1章节。

采用独立HTTP只读交互协议，保留既有顶部/Kanban/Org。桌面轴列+列表+事件详情，390px卡内时间与详情抽屉；类型颜色、正文四行截断/展开、筛选、回复定位和未知关联按批准基线实现。原生身份只用实际回报字段，晚补身份在旧事件重新投影。同名实例用runId区分。

后端按归档sequence增量分页，UI按Date.parse声明/观测时刻稳定排序；刷新保留可见事件锚点，不自动跳读，提供新交互查看按钮。来源与声明/观测、归档时间分开；本会话明确回报时间不冒充精确原生工具发生时间。旧MCP时间线明确提示未接入，独立网页为默认完整入口。

UI Check使用批准图和当前实际截图逐对核查；最终结果由真实浏览器/独立Reviewer填写。演示夹具来自临时工作区及明确演示团队，不混入真实业务队伍；夹具来源为ui-check/演示数据，测试截图标明身份。
